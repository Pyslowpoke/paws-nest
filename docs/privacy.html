你的生日，留在你的小窝里。

这个作品集体验版不要求登录，也不设置账户。生日只记录公历的月、日，不收集出生年份。

浏览器体验将生日、猫的外观、领养时间和已收信件保存在当前浏览器的本地存储中；Windows 客户端保存在当前系统用户的本地资料文件中。两者分别存档，不会自动跨设备同步。

页面没有外部统计、广告和远程字体。浏览网页时，托管服务商仍可能处理提供网页所需的网络请求和运行日志；“本地保存”不代表服务器完全没有访问日志。

可以在小屋里修改生日或清空生日。生日为空时不再生成新的生日信。清除对应浏览器的网站数据会删除浏览器存档；客户端资料位置见源码说明。

生日采用中国时区判断，2 月 29 日在非闰年于 2 月 28 日送信。七个全体公民法定节日使用本地公历、农历和节气计算，每年每节一封，不预测年度调休安排。清明使用平安、思念主题的来信。

软件或网页关闭期间不会后台推送。下次打开会补收相遇后错过的来信，长时间离线时最多回溯上一年和当年。演示信件有明确标记，不改变正式收信记录。

官网下载与续传

点击 Windows 下载后，官网会把已校验的软件分段暂存在当前浏览器的 IndexedDB 中，用于暂停或刷新后的续传。这些缓存只是公开的客户端文件，不含生日、聊天或密钥。可以在下载窗口点击“清理续传缓存”；它不影响游戏存档。清除整个站点的数据则也会删除网页游戏存档。

可选的 Windows AI 陪伴

网页不提供 AI 聊天。Windows 0.3 版可填写自己的 DeepSeek API Key：Key 由 Windows 加密保存在本机，仅随请求发送给 DeepSeek，不写入源码或上传 GitHub。聊天时会发送近期对话、小猫名称和启用的偏好记忆，受 DeepSeek 的服务政策约束，API 可能计费。

聊天记录与偏好存于本机 chat-state.json，可分别清空。关闭自动记忆后不再学习或发送已保存的偏好；近期对话仍会发送。想让旧话题不再进入上下文，请同时清空相关记忆与聊天记录。移除 Key 不会自动删除这些记录。
