爪爪小窝 · 使用说明

桌边的小小陪伴。从今天起，给日常添一点毛茸茸。

开始只需两步
  1. 把压缩包完整解压到一个自己的文件夹。
  2. 双击「启动爪爪小窝.cmd」，或者直接双击「PawsNest.exe」。
不需要安装开发工具、不需要 GPT 账号，也不需要联网生成小猫。请保留程序旁的所有文件。

01 · 先认识一下

第一次打开，给小猫起名字、选毛色、调整眼睛和小表情，再输入自己的公历生日。可以先跳过生日，以后在小屋「修改领养卡」里补充。

外观可以随时换。生日只记月和日，不需要出生年份。

02 · 和小猫过日子

  • 摸摸头、耳朵、尾巴和爪子，看看不同的小回应。
  • 可以喂日常猫粮、开一份罐头，也能让它在桌面或猫窝里睡觉。
  • 点击小屋里的「去桌面陪你」，唤出真正的透明桌宠。
  • 桌宠可拖动，提供小、中、大三种尺寸，也能切换置顶、安静陪伴和鼠标穿透。

03 · 有你的来信

点击猫窝旁的邮筒打开「小猫邮局」。领养时会收到一封相遇来信；生日和元旦、春节、清明、劳动节、端午、中秋、国庆，也会有一封属于当天的信。信角有小猫的署名和爪印。

每个节日每年投递一次，采用中国标准时间与法定节日本身的日期，不把调休的每一天都当作新节日。2 月 29 日生日在平年按 2 月 28 日送信。

软件完全退出时不会在后台推送；重新打开后，会补寄领养以来错过的来信，最多回看上一年和当年。信箱提供预览按钮，不会改动生日或正式收信记录。

04 · 和咪说说话

从小屋的聊天入口、桌宠聊天按钮或托盘「和小猫聊聊」打开对话。在「咪的小本本 → 聊天设置」中填写自己的 DeepSeek API Key，保存后即可发送。Key 不需要交给项目作者；基础养猫不需要 Key。

咪会听你说今天的心情、聊轻松的日常，遇到复杂任务可以承认不懂。它不写工作材料、不提供医疗或投资判断，也不承诺永远在线、要求你只依赖它。AI 的回答可能不准确，实际语气仍需试聊打磨。

Key 使用 Windows 加密保存在本机，不会上传 GitHub。发送时，近期对话和启用的偏好记忆会直接发送给 DeepSeek；此功能需要联网，API 可能按你的账户计费。请不要在聊天中发送密码等敏感资料。

「记住的小事」中可查看、添加、删除偏好，或关闭自动记忆。删除偏好后，旧聊天仍可能提到它；需要完整移除时请同时清空聊天记录。移除 Key 不会自动删除记录。

05 · 收起和退出

关闭小屋会保留桌宠。桌面右下角托盘里可以找到小猫图标；如果没看到，先展开「隐藏的图标」。托盘菜单可以打开小屋、信箱、恢复交互或退出程序。

开启鼠标穿透后，请通过托盘菜单恢复鼠标交互。彻底退出请点「退出爪爪小窝」。

06 · 常见问题

打开还是旧版？先在旧版「小猫在旁」的托盘菜单里退出，再双击新版。新旧版本共用同一份本地存档，旧毛色会保留；新版首次使用需补充领养卡。

只移动 exe 后打不开？需要完整的程序文件夹，请重新完整解压，不要单独移动 exe。

系统提示未知发布者？本体验版尚未购买代码签名证书。先确认文件来自本项目及可信交付位置，再决定是否运行。

存档在哪里？客户端保存在本机 AppData/Roaming/LittleDeskcat/companion.json。聊天记录与偏好在同目录 chat-state.json，Key 在 deepseek-key.bin。Key 与当前 Windows 用户绑定，不建议复制到其他电脑。卸载前如需保留养猫记录，可备份 companion.json。网页和客户端的存档各自独立，不自动同步。

有什么尚未实现？照片生成外观、AI 视频动画、走出页面过渡、音乐、亲密度养成、云同步、自动开机启动和商店发行仍是后续计划。
