# 爪爪小窝 0.3：只做一只愿意听你说话的小猫

## 开始聊天

打开 Windows 客户端，在小屋点击“和小猫聊聊”，或者使用桌宠工具栏中的气泡按钮、托盘菜单“和小猫聊聊”。首次使用，在“聊天设置”中填入你自己的 DeepSeek API Key。保存后发送一句日常问候即可验证连接。不需要在聊天软件或 GitHub 提供 Key。

Key 使用 Windows 提供的加密存储，仅保存在当前 Windows 用户的本机数据目录。程序通过 HTTPS 直接连接 api.deepseek.com；Key 用于请求认证，消息、最近 16 条聊天及已启用的偏好作为上下文发送给 DeepSeek。API 调用会消耗用户自己的 DeepSeek 额度。没有中转服务器，没有网页端 Key 输入框，也不会把 Key 上传到 GitHub。

目前默认使用 deepseek-flash 的非思考模式；可切换到 deepseek-v4-pro。模型名称依据 2026-11-02 的 DeepSeek 官方接口文档。没有提供真实 Key 前，仅能完成模拟接口与本地流程测试，不能据此声称已经验证某个账号的余额、权限或实际回复质量。

## 回复边界

小猫的使命是接住日常感受、轻松闲聊、记住得到许可的小偏好，陪伴用户安静一会儿。默认自称“咪”，通常回复 1～3 句，不抢着说教、不急于给方案，不强迫用户开心。

不承担代码、论文、合同、简历等工作任务；不提供医疗诊断、药物剂量、投资或法律判断。明确的复杂任务请求由本地规则给出简短的猫咪回应，普通对话由 DeepSeek 根据陪伴规则生成。角色规则、任务识别和输出长度限制共同约束行为，但生成式模型不能保证每条回答都完全符合预期，后续仍应根据实际聊天反馈迭代。

“今天写代码好累”属于情绪表达，可以接住；“帮我写一段代码”属于任务请求，会承认咪不懂。若用户提到眼前可能发生的自伤、伤人或身体急症，小猫认真提醒现实求助，不用听不懂来回避。

不要求独占关系，不让用户因离开而内疚，不声称能永远在线或替代现实中的人。可以说“咪在这里听你说”，不能承诺程序做不到的事。用户问身份时会说明是 AI 小猫。

模型只有文字回复能力，没有浏览器、电脑操作、文件读取、命令执行、购物、发消息或其他工具权限。

## 记住的小事

- 成功聊天后，程序可以记录明确的“我喜欢……”“我不喜欢……”“我偏爱……”“请叫我……”或“记住：……”表达。
- 也可以手动添加一条记忆，或点击自己消息下方的“记住这句”。不进行隐藏画像或根据情绪推断敏感属性。
- 保留最多 30 条记忆；可以逐条删除、全部删除，或者关闭自动记忆。关闭后不会自动记新偏好，也不会将已有偏好发送给 DeepSeek。
- 聊天记录最多保留 60 条。删除偏好不会删除原始聊天中的那句话；若希望它从后续上下文也消失，请同时清空聊天记录。
- 清空聊天不会清空偏好。移除 Key 会停止联网聊天，但保留本机记录。设置和删除操作会取消正在进行的回复，防止过期回复重新写回已清空的聊天。

## 存储位置与开发

本机数据位于 `%APPDATA%/LittleDeskcat/`：deepseek-key.bin 为加密 Key，chat-state.json 为聊天与偏好，companion.json 为原有猫咪资料。加密可以隔离其他 Windows 用户，但不承诺阻止同一 Windows 用户权限下的恶意程序。不要把整个用户数据目录作为源码发布。

这些文件均列入 .gitignore，不在安装包、源码 ZIP 或网页部署包内。运行检查使用单独的临时资料目录和虚构 Key。

`app/cat-persona.cjs` 定义宠物使命及任务边界；`app/chat-service.cjs` 负责接口、记忆、加密存储和取消机制；`app/room/chat-ui.js` 与 chat.css 为本地聊天面板。聊天入口仅在 Electron 客户端显示，公开网页版仍可离线完成原有互动。

测试：`node --test test/chat.test.cjs`。包含加密存储接口、Key 不进入上下文、偏好开关、删除、取消、异常、长度限制和任务边界。桌面检查额外使用 Windows 实际加密接口验证保存/读取、聊天面板、桌宠入口与异常提示，模型响应使用模拟结果，不消耗真实 API 额度。

参考：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[模型文档](https://api-docs.deepseek.com/quick_start/pricing/)、[Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)。
